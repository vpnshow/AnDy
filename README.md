## 安迪云(AnDy)VPN协议与使用特点

**安迪云(AnDy)** 全部套餐使用 **VLESS 协议**，支持将通用订阅导入兼容客户端。套餐说明指出各档线路相同，主要区别在于**流量额度、设备数量与套餐速率**，可结合预算和实际使用量选择。

- **周期套餐**：每月提供固定流量，适合有持续使用需求的用户；最低年付档每月 50GB，月付档覆盖 100GB 至 1000GB。
- **不限时流量包**：一次购买 1000GB 总流量，不按月刷新，也不代表无限流量。
- **速率与设备**：周期套餐标注 500Mbps 至 5Gbps、2 至 8 台设备；不限时套餐标注 1Gbps、10 台设备，具体限制见下表。标注速率不等于任何网络环境下都能达到的实际速度。
- **流媒体与节点**：套餐说明标注支持流媒体解锁、可用所有节点，具体平台与地区可用性以节点当前状态为准。
- **通用订阅**：可使用兼容 VLESS 及面板订阅格式的第三方客户端，安装与导入可参考[客户端教程汇总](https://eoht.net/serve/antiwall/summary)。
- **退款规则**：套餐说明标注不支持退款，购买前应确认流量、设备数与付款周期。

## 安迪云(AnDy)VPN续费、换套餐与流量重置

**续费和重置流量是不同操作**。如果当月流量已经用完，直接续费相同套餐不会立即恢复当月额度。

- **每月重置**：周期套餐的月度额度按账单日重置，季付、年付等较长周期也按月刷新；当月未用完的流量不结转到下个月。
- **续费相同套餐**：延长使用时长，不立即重置当月流量，需要等待下一次账单日重置或另行购买当月流量重置。
- **重置当月流量**：帮助说明标注使用达到 90% 后会显示重置入口。购买重置会清零当月已用流量、恢复套餐额度，原有到期日不变。
- **更换更高档套餐**：可按流量需求升级，但新套餐会覆盖旧套餐，操作前需核对套餐内容与结算结果。
- **重复购买一次性套餐**：不累加旧套餐剩余流量，直接重置为新购额度；应与周期套餐的续费、月度重置区分。

### 最低多少钱，50GB 是全年总流量吗？

最低年付为 **¥30/年、每月 50GB**，折合 **¥2.50/月**，并非全年只有 50GB。按月购买可选择 **¥5/月、每月 100GB**的套餐，以上均为使用优惠码前的标价。

### 不限时套餐和月付-1000G 有什么区别？

**一次性-1000G** 为 ¥100、总流量 1000GB，用完为止，标注 1Gbps、10 台设备；**月付-1000G** 为 ¥25/月、每月 1000GB，标注 5Gbps、8 台设备。两者的流量刷新方式、速率与设备限制不同。

### 支持哪些客户端？

安迪云支持 **VLESS 与通用订阅**，可选择兼容相应协议及面板订阅格式的客户端。配置方法可参考[Clash Verge Rev](https://eoht.net/serve/antiwall/clash-verge-rev)、[Shadowrocket](https://eoht.net/serve/antiwall/shadowrocket)和 [v2rayN](https://eoht.net/serve/antiwall/v2rayn)教程。

### 当月流量用完，续费后为什么还不能用？

续费相同套餐只延长使用时长，不会立即重置当月流量。可以等账单日自动刷新、按面板规则购买当月流量重置，或核对更高档套餐后升级。
